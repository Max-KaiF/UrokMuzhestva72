Текущая фаза

Пять ролей

Роль Что делает
Заявитель Подаёт заявку, выбирает спикера, подтверждает готовность, отмечает урок проведённым, оставляет отзыв со ссылкой на пост
Фонд-координатор Берёт заявку в обработку, подбирает и подтверждает спикера, при необходимости заменяет
Спикер-ветеран Видит назначенные уроки, проходит допуск по возрастным группам, отмечает недоступные даты, оставляет отзыв
Оператор Модерирует заявителей и спикеров, ведёт реестры, закрывает заявки, формирует отчёты и CSV-экспорт
Администратор новостей Ведёт ленту новостей на публичной части сайта

Техническая архитектура

Стек

PHP без фреймворка — index.php (маршрутизация) + lib.php (бизнес-логика), около 5800 строк

База данных

PDO, два драйвера — MySQL в проде, SQLite для разработки; идемпотентные миграции

Безопасность кода

Параметризованные запросы, экранирование вывода, CSRF-токены, пароли — bcrypt

Аутентификация

Логин/пароль + обязательный одноразовый код на email для всех ролей, блокировка после 5 попыток
